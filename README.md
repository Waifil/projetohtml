🍕 JERRERS — Sistema de Pedidos Online

Projeto acadêmico desenvolvido para a JERRERS, uma pizzaria fictícia, com o objetivo de criar uma experiência simples e intuitiva para que os clientes pudessem consultar o cardápio, selecionar produtos e realizar seus pedidos diretamente pelo site.

🎯 Objetivo do Projeto

O principal objetivo foi desenvolver um site de pedidos online para uma pizzaria, permitindo que o cliente escolhesse os produtos disponíveis no cardápio e adicionasse os itens desejados a um carrinho de compras integrado.

O carrinho permite ao cliente visualizar os produtos selecionados, conferir os itens do pedido e prosseguir para a finalização da compra, simulando o fluxo de um sistema real de pedidos.

🍕 Principais funcionalidades
📋 Visualização do cardápio da JERRERS;
🍕 Seleção de produtos;
🛒 Sistema de carrinho integrado;
➕ Adição de produtos ao carrinho;
➖ Alteração dos itens selecionados;
🗑️ Remoção de produtos do carrinho;
💰 Visualização do valor total do pedido;
✅ Finalização do pedido.
🛠️ Tecnologias Utilizadas
HTML5 — estrutura e organização das páginas;
CSS3 — estilização e criação da interface;
JavaScript — implementação da lógica e interatividade do sistema;
SQL — conhecimentos básicos aplicados ao conceito de armazenamento e manipulação de dados;
Git e GitHub — controle de versão e gerenciamento do projeto.
📚 O que foi aprendido

O desenvolvimento do projeto permitiu colocar em prática conhecimentos adquiridos durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

Entre os principais aprendizados estão:

Estruturação de páginas utilizando HTML5;
Criação de interfaces utilizando CSS3;
Desenvolvimento de funcionalidades interativas com JavaScript;
Implementação da lógica de um sistema de carrinho;
Manipulação e atualização de informações exibidas ao usuário;
Organização do fluxo de um pedido, desde a seleção dos produtos até sua finalização;
Aplicação de conceitos básicos de banco de dados e SQL;
Utilização do Git e GitHub para controle de versão;
Organização e documentação de um projeto de software.
🚧 Status do Projeto

Concluído — Projeto Acadêmico.

O projeto foi desenvolvido com finalidade educacional, servindo como prática para o desenvolvimento de aplicações web e implementação de funcionalidades comuns em sistemas de pedidos online.
